Support

Something not working, or a question the tester page does not answer? Write to me, from inside the app or by email.

Getting in touch

From inside the app
Every screen but the one where you set a password from an email has a Report a problem link in its footer. It opens your own email app with a message already started: which version and build you are on, which screen you were looking at, and which browser. Nothing is sent until you press send, and you can read and change every word first. Add what happened and what you expected instead.
By email
dave@madcowhq.com.
How long you will wait
I read that address daily, so expect a reply within a couple of days. If you write during a regatta weekend it will probably be Monday.
What helps
The version and build from the footer, which screen you were on, and what the screen said. The in-app link fills in the first three. A screenshot is worth a paragraph, but check that it shows no name or email you would rather not send.
Which version you are on
The footer of every screen ends with a version and a build, for example v1.0.1 · build a90fd5b. The build's seven characters name the exact code, so quote both when you write. Taskr is deployed the same day a change is finished, and an open app picks the new build up on its own.
